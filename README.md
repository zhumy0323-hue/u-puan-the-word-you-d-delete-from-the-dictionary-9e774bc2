## What this entry is

One word: **inflammable**.

## Why it's good

It looks like it means "not flammable" — the `in-` prefix says safe — and it actually means "flammable". It is a word that lies to you at the exact moment you most need the truth, on a label, on a truck, next to a flame — the one word in the dictionary that is itself a fire hazard. Deleting it costs nothing: "flammable" already exists and says the same thing without the trap. The joke is in the word itself — one read and you can picture someone relaxing around the very thing that is about to catch fire.

## How to run

```sh
python3 main.py
```

This writes the single word `inflammable` to `/output/entry.txt` (UTF-8, one line, no trailing newline). It uses only the Python standard library, no network, no randomness, so repeated runs produce identical bytes.
